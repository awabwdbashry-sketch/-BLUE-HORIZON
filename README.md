# ⚓ BLUE HORIZON YACHTS — يخوت الأفق الأزرق

## 🌊 نبذة عن المشروع

**BLUE HORIZON YACHTS** هو موقع ويب فاخر ومتجاوب مصمم لتقديم تجربة بحرية راقية لعشاق اليخوت والرحلات البحرية.

الموقع يجمع بين التصميم العصري، الصور البحرية الفاخرة، الحركات التفاعلية، ونظام طلب حجز بسيط، مع واجهة عربية كاملة بتصميم RTL.

---

## ✨ المميزات

- ⚓ عرض أسطول اليخوت الفاخرة.
- 🛥️ تفاصيل ومواصفات كل يخت.

- 🌊 تأثير Parallax لصورة الـHero.
- 🖱️ تأثير Tilt تفاعلي على بطاقات اليخوت.

# ⚓ BLUE HORIZON YACHTS

## 🌊 Project Overview

**BLUE HORIZON YACHTS** is a premium responsive website designed for a luxury yacht and marine travel experience.

The project combines a modern luxury interface, marine-inspired visuals, interactive animations, yacht showcases, travel experiences, destinations, customer reviews, and a front-end booking request form.

The website is built with a fully Arabic RTL interface while maintaining a premium and modern visual identity.

---

## ✨ Features

- ⚓ Luxury yacht fleet showcase.
- 🛥️ Yacht details and specifications.
- 🌅 Marine trips and experiences.
- 🗺️ Travel destinations section.
- 📅 Interactive booking request form.
- ✅ Booking form validation.
- 🎉 Booking success modal.
- ⭐ Customer reviews section.
- 📱 Fully responsive design.
- 🍔 Responsive mobile navigation.
- 🎨 Luxury marine-inspired UI.
- ✨ Scroll reveal animations.
- 🌊 Hero image parallax effect.
- 🖱️ Interactive yacht card tilt effect.
- 🔝 Back-to-top button.
- 🔗 Smooth scrolling navigation.
- 🧭 Active navigation section highlighting.
- 🖼️ Lazy-loaded images with fallback placeholders.
- ⌨️ Escape-key support for closing the booking modal.

---

## 🛥️ Yacht Fleet

The website showcases several luxury yachts, including:

- ⚓ Ocean Pride
- 💎 Azure Dream
- 🏊 Selena Lux
- 🌊 Pearl Classic

Each yacht includes information such as:

- Guest capacity
- Number of cabins
- Available facilities
- Daily starting price
- Yacht description

## 🌅 Marine Trips

The website features different marine experiences, including:

- 🌇 Golden Sunset Cruise
- 🤿 Diving & Coral Reef Adventure
- 👨‍👩‍👧‍👦 Grand Family Trip
- 🏝️ Hidden Islands Tour

---

## 📅 Booking System

The website includes an interactive booking request form where users can enter:

- 👤 Name
- 📞 Phone number
- 🛥️ Yacht selection
- 📅 Trip date
- 👥 Number of guests

The form validates the required fields before simulating a successful booking request.

> Note: The current booking system is a front-end simulation and does not connect to a backend or database.
